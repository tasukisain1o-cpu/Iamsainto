# Security policy

## Reporting a vulnerability

Please report security issues privately to `businesssainto@gmail.com`. Do not publish working exploits, leaked credentials, personal data or instructions that could harm visitors. Include the affected page, reproduction steps and expected impact.

The website is static and does not accept accounts, passwords, payments or form submissions. Never send API keys, passwords, recovery codes or wallet seed phrases through the website or email.

## Supported version

Only the version currently published from the `main` branch is supported. GitHub Pages provides HTTPS and edge-level availability protection; application-level code cannot guarantee protection against every denial-of-service attack.
